### Featured Projects

**🔐 [Secure Chat — End-to-End Encrypted Messenger](https://github.com/SickSect/Secure-Socket-Chat)**  
TCP-based encrypted chat with forward secrecy (ephemeral ECDH key exchange) and persistent RSA identity keys. Custom cryptographic protocol, multithreaded client-server architecture, documented message spec. *(Java)*

**🧪 [Mobile & API Test Automation Framework](https://github.com/SickSect/Mobile-and-API-Autotest-framework)**  
Test automation framework combining mobile UI tests (Appium) + API tests (custom HTTP client on `java.net.http`) + database layer (JDBC). Built from scratch, no heavy external test libraries. *(Java)*

**🤖 [Nutrition Tracker Bot with Local AI](https://github.com/SickSect/CaloriesCalc)**  
Telegram bot for daily nutrition tracking with a local AI advisor (Ollama) — no external AI APIs, everything runs on-device. *(Python)*

**🎮 [Asset Assistant for Blender with Local AI](https://github.com/SickSect/BlenderAgent)**
Blender add-on that audits your game assets, fixes what is broken and carries the rest of the pipeline — UV, baking, retopology, export. Works with a local model (Ollama), no API keys needed. (Blender/Python)
